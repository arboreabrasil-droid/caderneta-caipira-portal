# Caderneta Caipira - Controle de Chuvas

Sistema de monitoramento e controle pluviométrico para pequenas propriedades rurais e sítios de lazer.

## 🌧️ Funcionalidades

- **Dashboard completo** com estatísticas mensais e anuais
- **Registro diário** de precipitação
- **Gráficos interativos** de chuva x meses
- **Comparativos** ano/ano e mês/mês
- **Armazenamento seguro** no Google Drive do usuário
- **Interface responsiva** para desktop, tablet e celular

## 🚀 Como usar

### 1. Clonar o repositório
```bash
git clone [URL-DO-SEU-REPOSITORIO]
cd caderneta-caipira-controle-chuvas
```

### 2. Instalar dependências
```bash
npm install
```

### 3. Executar em desenvolvimento
```bash
npm run dev
```

### 4. Build para produção
```bash
npm run build
```

## 📦 Deploy no Vercel

1. Faça push do código para o GitHub
2. Conecte seu repositório ao Vercel
3. O deploy será automático a cada commit

## 🎨 Tecnologias

- React 18
- Vite
- Tailwind CSS
- Chart.js
- Google Drive API
